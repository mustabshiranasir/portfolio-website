## 📌 Features

- **Hero & Interactive Bio**: Modern dark slate theme featuring an interactive particle background (`tsParticles`) and dynamic dynamic typing text (`Typed.js`).
- **Semantic & Accessible Markup**: Structured using semantic HTML5 elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **Featured Projects**: Displays professional software & AI projects with direct GitHub links, technology tags, and concise summaries.
- **Categorized Technical Skills**: Built using native CSS Grid to cleanly lay out skill badges across Web, Mobile, Database, Backend, and Tooling stacks.
- **Work & Education Experience**: Clean timeline cards detailing software developer internships and CS academic background.
- **Interactive Contact Form**: Integrated client-side validation with mailto dispatching capabilities.
- **100% Mobile Responsive**: Tested and optimized for mobile (~375px), tablet, and desktop viewports using CSS Grid, Flexbox, and Media Queries.

## 🚀 How to Run Locally

Since this is a static website, no complex setup or `npm install` is required!

### Option 1: Open Direct in Browser
1. Clone the repository:
   ```bash
   git clone https://github.com/mustabshiranasir/portfolio-website.git
   ```
2. Navigate to the project directory and open `index.html` in your favorite web browser.

### Option 2: Live Server (VS Code Extension)
1. Open the cloned folder in **VS Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html` and click **Open with Live Server**.

### Option 3: Python Local HTTP Server
Run the following command in your terminal within the project directory:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.

## � Deployment

This project is set up for GitHub Pages deployment through the workflow in [.github/workflows/pages.yml](.github/workflows/pages.yml). Once the workflow runs successfully in GitHub Actions, the site will be published at:

- https://mustabshiranasir.github.io/portfolio-website/

To enable deployment in GitHub:
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Choose the GitHub Actions source.
4. Push to the main branch to trigger the deployment workflow.
